# Spoorthi S. Patil — Developer Portfolio

Responsive personal portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — portfolio sections and project descriptions
- `style.css` — dark violet/cyan visual design and responsive layouts
- `script.js` — mobile navigation, current year, copy-email interaction

## Run locally
Open `index.html` in a modern browser. No package installation is required.

## Publish with GitHub Pages
Repository: `spoo-thi.github.io`

In GitHub, open **Settings → Pages** and select **Deploy from a branch**, choose **main** and **/(root)**, then Save.
