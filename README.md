# Spoorthi S. Patil — Portfolio Website

A responsive, dark-themed portfolio website tailored to the details in the supplied resume and the Customer Success Intern application.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox, or another modern browser.

No build step, package installation, or backend is required.

## Publish on GitHub Pages
1. Create or open the repository used for your GitHub Pages site.
2. Upload the contents of this folder (the `index.html`, `style.css`, `script.js`, and `assets` folder) to the repository root.
3. Commit the changes.
4. In repository Settings → Pages, configure deployment from the main branch and root folder if not already enabled.
5. Wait for deployment and open your Pages URL.

## Customize before publishing
- Update the email and LinkedIn URLs if needed.
- Add your GitHub profile URL when ready.
- Add a resume PDF and link it from the hero section if you want a downloadable resume button.
- Your supplied portrait is used in the hero section (`assets/spoorthi-profile.jpg`). Replace it if you want a different profile photo.
- Replace the illustrative project previews in `assets/` with real screenshots of your own working projects when available.
- Link project cards to repositories or live demos only after verifying those URLs.

## Accuracy note
Project preview images are illustrative UI mockups created for the portfolio. They are not screenshots from running applications. LinkLens is labeled as a concept/in progress because the supplied resume described it as planned. Only claim features that you have implemented and can demonstrate.
